# Tarefa-13-estatistica
ReadMe tarefa 13
Integrantes do Grupo: Carolina Ferreira Onias Luciana Miki Sumi Melissa Rebechi Santana
O objetivo do nosso script foi apresentar e aplicar conceitos de probabilidade e distribuições de probabilidade nas Ciências dos Alimentos, utilizando dados reais da Tabela Brasileira de Composição de Alimentos (TBCA). Utilizamos diferentes distribuições estatísticas para representar e interpretar dados relacionados à composição dos alimentos, além de calcular probabilidades e visualizar os resultados por gráficos.
Para isso, escolhemos a variável “Carboidratos Totais Disponíveis Média (g)” para trabalhar com a distribuição Normal, calculando a média, o desvio-padrão e a variância amostral. Com esses parâmetros, foram calculadas probabilidades para diferentes intervalos de concentração de carboidratos e também o percentil 90.
Também apresentamos características, aplicações estatísticas e parâmetros das distribuições t de Student, Qui-Quadrado e F de Fisher. Na distribuição t, foram analisadas probabilidades relacionadas a uma estatística amostral e calculado o percentil 95. Na distribuição Qui-Quadrado, foi analisada uma estatística associada à variância amostral. Já para a distribuição F, foi utilizada a variável “Umidade Média (g)” presente nas classificações “Carboidratos Disponíveis” e “Carboidratos Não Disponíveis”, para podermos trabalhar a razão entre as variâncias dos dois grupos.
Os gráficos ajudam na visualização do comportamento das distribuições e da influência de seus parâmetros (média, desvio-padrão e graus de liberdade). Também foram representadas as regiões correspondentes às probabilidades calculadas e seus percentis, em forma de gráfico.
Para reproduzir a análise, recomendamos utilizar o Python, em plataformas como o Google Colab. Todas as bibliotecas utilizadas devem ser importadas no código: NumPy, Pandas, Matplotlib e SciPy. O arquivo “Perfil_Carboidratos_TBCA.xlsx” deve ser anexado, pois foi utilizado como base de dados. A planilha deve estar no mesmo ambiente em que o código será executado, e os nomes das abas devem ser mantidos, no caso o “Carboidratos Disponíveis” e “Carboidratos Não Disponíveis”. Depois que a base for carregada, recomendamos executar os códigos em células separadas.
